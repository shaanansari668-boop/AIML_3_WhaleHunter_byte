# Customer Segmentation (Task 3)

## Problem
Segment customers by purchasing behavior and identify the highest-spending "whale" cluster.

## Approach
- RFM feature engineering
- K-Means clustering with silhouette-based k selection

## Results
- Chosen k: 2
- Whale cluster (Cluster 1): Recency ≈ 26 days, Frequency ≈ 8.4 orders, Monetary ≈ £4,548

## Outputs
- Silhouette score plot
- Cluster map
- Cluster profiles
- Targeted marketing brief

## How to Run
Run notebook.ipynb in Google Colab.
