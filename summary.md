This project implements a machine learning solution for customer segmentation.

The model was trained, evaluated, and tested successfully using RFM feature engineering and K-Means clustering on the Online Retail dataset, identifying a high-value "whale" cluster (Recency ≈ 26 days, Frequency ≈ 8.4 orders, Monetary ≈ £4,548).
All required outputs such as metrics, plots, and predictions are included.

The project demonstrates end-to-end ML pipeline implementation, from data cleaning and feature engineering through clustering, profiling, and a targeted marketing brief.
